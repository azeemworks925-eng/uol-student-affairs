Palette comparison: Forest and Indigo, light and dark

Identical components rendered with the exact values from the Frontend Design Research Report. Nothing here is approved. Use Tab to see live focus rings. The grey page around the panels is neutral on purpose.

Show: Tip: show only the two dark panels to judge the accent against Resolved.

1. Buttons

Primary, secondary and quiet, in both densities, with hover, focus and disabled states shown statically.

2. Complaint status badges, and the accent against Resolved

The four statuses from DEC-221, each with an icon and a label. The second block puts the accent's three uses (solid button, current navigation, accent text) directly beside the Resolved badge, on the canvas and on a card. This is the comparison the report says decides between Forest and Indigo.

3. Text inputs, selects and textareas

Default, filled, focus, error and read-only states. Roomy is the student complaint form; compact is the advisor's status update, where a rejection reason is mandatory (DEC-221).

4. Standard and compact cards

A student's complaint card (roomy) and a Batch Advisor's inbox card (compact), with hairline dividers instead of nested boxes.

5. Navigation sidebar

Student sidebar (roomy) and Batch Advisor sidebar (compact). The current item uses the accent tint, accent text and weight 600; one item shows hover and one shows the focus ring.

6. Student Dashboard, phone width

The three confirmed sections (DEC-282): Your Actions, Section Updates and Quick Access. No statistics. All names are fictional.

7. Contrast measured from the rendered page

Computed in the browser from the colours actually rendered above, using the WCAG 2.x contrast formula. Text needs 4.5:1; control boundaries and focus rings need 3:1. "Advisory" marks a pair that is below 3:1 but not a WCAG failure, because something else (such as the label) identifies the control.

8. Token values used

Values marked "derived" are not in the research report. They were derived for Indigo with the same method as Forest and must be reviewed before any decision.
