# UOL Student Affairs

### Student Affairs & Engagement Portal

UOL Student Affairs is an academic software engineering project focused on providing a centralized digital platform for student engagement, communication, and student affairs workflows at the University of Lahore.

## Project Status

Under Development

## Project Objectives

- Provide a structured channel for student feedback and engagement.
- Support academic advisors in managing student concerns.
- Facilitate suggestions and appreciation submissions.
- Support advisor-student meeting coordination.
- Provide meaningful aggregate insights for departmental decision-making.

## Planned Technology Stack

- Python 3.13
- Django 5.2 LTS
- MySQL 8.4 LTS
- HTML, CSS and JavaScript
- Bootstrap 5.3
- Git and GitHub
